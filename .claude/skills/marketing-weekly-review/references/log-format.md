# Weekly review — log format

The performance journal lives at `data/performance-log.md` (append-only, newest entry at the **top**). Each weekly review adds one entry in this exact shape:

```
## Week of YYYY-MM-DD

**Posted this week:** <video title / idea> — <platforms it went to>

**Results:**
- TikTok: <views>   (Δ vs that platform's recent avg)
- Instagram: <views>
- Facebook: <views>
- YouTube: <views>
- Downloads this week: <N>  (all-time <M>)

**Grading last week's prediction:**
<Quote the prediction from the previous entry, then the actual outcome, then a verdict: HIT / MISS / PARTIAL. One or two sentences. If there was no prior prediction, say "first logged week — no prediction to grade.">

**Experiment status:**
<Name the running experiment, restate its stop rule, then the call: CONTINUE / KILL / REST. e.g. "Instagram pain-first + 5-hashtag + cold-open. Rule: rest 7 days if 2 posts stay under 15. This post: 41 views → CONTINUE, it cleared 30.">

**What I changed and why:**
<The lever pulled this round, traced to a number. Specific.>

**Prediction for next week:**
<A single testable signal to check at the next review. e.g. "If the relight format holds, IG should stay above 30 and TikTok clear 600.">
```

## Grading rules

- **Quote the previous prediction verbatim** before grading it. The whole point is accountability — you graded yourself, in your own prior words.
- A prediction is **HIT** only if the actual number met the signal it named, **MISS** if it clearly didn't, **PARTIAL** if mixed or within noise.
- Compare each platform's result to **that platform's own recent average**, not to other platforms (they operate on different scales).

## Honesty rules (do not skip)

- **One post is not proof.** Name the sample size. A single good or bad number is a signal, not a verdict — say so.
- **Don't claim causation from view counts alone.** "IG rose after the hashtag fix" is correlation; the algorithm, timing, and luck all move numbers too. Use "consistent with" not "proves."
- **Respect each experiment's own stop rule** even if you'd like to keep going. If the rule says rest the account, recommend resting.
- If the numbers are flat or down, **say it plainly** and propose the next change — don't soften it into false progress.
