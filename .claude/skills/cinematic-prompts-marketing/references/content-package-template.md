# Content Package — give a title, get descriptions + viral tags

## How to use (in Claude Code)
Tell the agent:  **"Content package for: <your video title or idea>"**
Optionally add the style + daylight lighting shown, and which selling point it proves.

The agent then:
1. **Researches current viral/trending tags** per platform (web search for what's
   trending now in AI-video / cinematic / the video's topic) — not generic evergreen tags.
2. Writes a **description tailored to each platform** (different length, tone, hook).
3. Returns everything below, ready to copy-paste. You post manually for now.

Always work in the two selling points: **no wasted credits** and **style + daylight
lighting, both by choice**. Optimize wording toward **App Store downloads**.
