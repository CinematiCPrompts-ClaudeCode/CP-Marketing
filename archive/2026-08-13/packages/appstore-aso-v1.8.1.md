## The mechanics (why this plan looks like it does)
Apple indexes for search ONLY: **App Name** (highest weight) → **Subtitle** (second) → **Keyword field** (third). Plus download velocity/conversion. **The description is NOT indexed** (that's Google Play) — it drives *conversion*, not discovery. So ranking is won in the name/subtitle/keywords.

**Current state:** Name `Cinematic Prompts` · Subtitle `Cinematic AI prompt generator`.
All four target tokens (ai, cinematic, prompt, generator) technically exist across name+subtitle — so the app is *eligible* for those queries but ranks too low to surface. Fix = push the tokens into the **highest-weighted field (the name)** + keep velocity climbing (86 downloads/30d and rising is already helping).
