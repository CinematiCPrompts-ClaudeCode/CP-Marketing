# First run after the wipe — paste this to the agent

Fresh start. Ignore any prior lessons — they're archived and out of scope. Derive
everything from the data in front of you; do not reconstruct old rules from memory.

1. Run `./run.sh` to pull the latest numbers.
2. Read ONLY `dashboard/data.js`. For each platform (TikTok, Instagram, Facebook, YouTube):
   rank every post by views, pick the top 3–5, and name the concrete pattern each used —
   hook shape, subject, caption style, length. Trace toward installs where the data lets you.
3. Write the findings into `LESSONS.md` → *What wins*, one line per pattern, each with its
   real view count. A pattern only goes in if you can point to a number for it.
4. Name the weakest channel and one concrete, testable experiment for it (with a stop signal).
5. Draft next week's content package from what you just found — then run
   `./check.sh <package>` and make it CLEAR before presenting it.

That's the whole loop: analyse the real results, write down only what the numbers support,
build the next package on it, and let the gate keep it honest.
